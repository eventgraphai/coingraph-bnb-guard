# Build plan (short version)

## Order of work (stop wherever time runs out; the demo must still work)

1. Token checks for BNB Chain tokens, tested on real Four.meme and Flap launches.
2. Signed answers + answer hash on BNB Smart Chain.
3. Guard contract on BNB Smart Chain that rejects an "avoid" swap.
4. Demo agent end to end: refused trade (copycat BTCB), approved trade (CAKE, $1, mainnet).
5. Extras: Cloudflare Workers hosting, AWS Bedrock agent, x402 pay per check, backtest on recent launches.
6. Friday morning: freeze, backup demo video, submission, rehearsal.

## Rules for claims

- "Built on BNB Chain", never "partnered with" or "backed by" Binance or BNB Chain.
- "Provable" or "verifiable on-chain", never "verified". Small real amounts in the demo, labelled as such.
- Backtest numbers exactly as measured, with the method.
- No Binance logo or official art.
