Verify from the command line

curl -s https://guard.coingraph.ai/api/evidence/<evidenceHash> -o answer.json
cast keccak "$(cat answer.json)"     # equals the evidenceHash in the ProofLog event

The ProofLog contract 0x186e…7f5d emits Answered(answerHash, token, verdict, chainId, evidenceHash, issuedAt) for every answer.
