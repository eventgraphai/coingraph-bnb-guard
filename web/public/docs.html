Step 1 · no key

Try it in 10 seconds

Paste this in a terminal. It checks TRX for a $1,000 buy on BNB Smart Chain and records the answer on chain.

Terminal
curl "https://guard.coingraph.ai/api/check?token=0xCE7de646e7208a4Ef112cb6ed5038FA6cC6b12e3&usd=1000"

Change token to any BNB Smart Chain contract address and usd to your order size (1 to 100,000). You get back proceed, caution or avoid, every reason, and a BscScan link to the record. Prefer clicking? Use the check box on the homepage.

Step 3 · no key

Use it from code

Call the check before every buy, and stop unless it says proceed.

TypeScript
async function safeToBuy(token: string, usd: number) {
  const url = `https://guard.coingraph.ai/api/check?token=${token}&usd=${usd}`;
  const check = await (await fetch(url)).json();
  if (check.verdict !== "proceed") {
    console.log("Stopped:", check.findings[0].text);
    return false;
  }
  console.log("OK. Record:", check.proof?.explorer);
  return true;
}
Python
import requests

def safe_to_buy(token: str, usd: int) -> bool:
    check = requests.get("https://guard.coingraph.ai/api/check",
                         params={"token": token, "usd": usd}, timeout=120).json()
    if check["verdict"] != "proceed":
        print("Stopped:", check["findings"][0]["text"])
        return False
    return True

On chain

Guard contract

The guard wraps a PancakeSwap v2 buy. It swaps only with a recent CoinGraph answer, signed for that exact agent, token and amount, that says proceed. Anything else reverts and the BNB stays in the wallet.

ContractAddress (BNB Smart Chain mainnet)

CoinGraphGuardAtlas0xf86e3867cee19d56cacfb704dabb1b138af8b0ed · also verifies Atlas Oracle's signed price in the same transaction
ProofLog0x186ef344dcd0dd74d292a5d2b4433d77e19f5f7d · every answer recorded before the trade
Solidity
struct Answer {
  address agent;        // who may use this answer
  address token;        // the token that was checked
  uint256 maxAmountIn;  // largest BNB amount (wei) it covers
  uint8   verdict;      // 1 proceed, 2 caution, 3 avoid
  uint64  issuedAt;     // valid for 5 minutes, once
  bytes32 evidenceHash; // keccak256 of the full check
}

function buy(Answer calldata a, bytes calldata sig,
             uint256 amountOutMin, address[] calldata path,
             uint256 deadline) external payable;

Why a buy reverts

ErrorMeaning
NotProceedThe answer says caution or avoid.
OracleDeviationThe pool price is too far from Atlas Oracle's signed price (Atlas guard).
AmountTooLargeMore BNB than the answer covers.
AnswerExpired / AnswerUsedOlder than 5 minutes, or already used.
NotYourAnswer / WrongToken / WrongSignerSigned for another agent or token, or not by CoinGraph.
Using the guard with your own agent:signed answers are issued for your agent's wallet address. During the hackathon this is set up per team: open an issue on GitHub or email support@coingraph.ai.

Verify an answer

  1. Run a check on guard.coingraph.ai and click Download evidence.
  2. Hash the file with keccak256.
  3. Open the record on BscScan and compare it with the evidenceHash in the transaction.

More with a CoinGraph key

You don't need this for the hackathon. With a free account, the wider CoinGraph platform adds the top 1,000 tokens on every chain, sized checks with your own rules, and five ready-made agents (Trade Gatekeeper, Wallet Guard, Due Diligence Analyst, Portfolio Checkup, Daily Market Brief).

  1. Get a key at coingraph.ai/account/keys (Google or email). New accounts get 500 free credits.
