Step 1

Get an API key

The Guard API on this site needs no key. For the CoinGraph API, MCP and agents you need a free CoinGraph account:

  1. Open coingraph.ai/account/keys and sign in with Google or email.
  2. Click Create key and copy it. It starts with cg_live_ and is shown once.
  3. Store it as an environment variable, never in your code:
Terminal
export COINGRAPH_KEY="cg_live_…"
Credits:new accounts start with 500 free credits (1 credit = $0.01). See pricing or the full keys guide.
Free · no key

Guard API

Check any BNB Smart Chain token for an order size. CoinGraph simulates the buy and sell on PancakeSwap, reads CoinMarketCap data, compares the price with Atlas Oracle, weighs Cournot market risk, and records the answer on BNB Smart Chain.

curl
curl "https://guard.coingraph.ai/api/check?token=0xCE7de646e7208a4Ef112cb6ed5038FA6cC6b12e3&usd=1000"
TypeScript
const res = await fetch(
  "https://guard.coingraph.ai/api/check?token=" + token + "&usd=1000"
);
const check = await res.json();
if (check.verdict !== "proceed") throw new Error(check.findings[0].text);
// check.proof.explorer is the on-chain record of this answer

Parameters

NameDescription
tokenThe token's BNB Smart Chain contract address (0x…).
usdOrder size in US dollars, 1 to 100,000. Default 500. Price impact and liquidity are judged for this size.

CoinGraph API

The full CoinGraph API covers the top 1,000 tokens across chains: market, on-chain flows, order books, futures, holders, contract security and supply. Base URL: https://coingraph.ai/api/v1.

Standard check (free, no key)

curl
curl https://coingraph.ai/api/v1/evaluate/chainlink

Check sized to your order (25 credits)

curl
curl -X POST https://coingraph.ai/api/v1/evaluate \
  -H "Authorization: Bearer $COINGRAPH_KEY" \
  -H "Content-Type: application/json" \
  -d '{"token": "chainlink", "size_usd": 1000}'

Every answer has an id; GET /verify/{id} returns its proof. All 13 endpoints with real examples: coingraph.ai/docs/api.

On chain

Guard contract

The guard wraps a PancakeSwap v2 buy. It swaps only with a recent CoinGraph answer, signed for that exact agent, token and amount, that says proceed. Anything else reverts and the BNB stays in the wallet.

ContractAddress (BNB Smart Chain mainnet)
CoinGraphGuard0x7f914975c2af57253a707fb2c2e44776dc45000b
CoinGraphGuardAtlas0xf86e3867cee19d56cacfb704dabb1b138af8b0ed · also verifies Atlas Oracle's signed price in the same transaction
ProofLog0x186ef344dcd0dd74d292a5d2b4433d77e19f5f7d · every answer recorded before the trade
Solidity
struct Answer {
  address agent;        // who may use this answer
  address token;        // the token that was checked
  uint256 maxAmountIn;  // largest BNB amount (wei) it covers
  uint8   verdict;      // 1 proceed, 2 caution, 3 avoid
  uint64  issuedAt;     // valid for 5 minutes, once
  bytes32 evidenceHash; // keccak256 of the full check
}

function buy(Answer calldata a, bytes calldata sig,
             uint256 amountOutMin, address[] calldata path,
             uint256 deadline) external payable;

Why a buy reverts

ErrorMeaning
NotProceedThe answer says caution or avoid.
OracleDeviationThe pool price is too far from Atlas Oracle's signed price (Atlas guard).
AmountTooLargeMore BNB than the answer covers.
AnswerExpired / AnswerUsedOlder than 5 minutes, or already used.
NotYourAnswer / WrongToken / WrongSignerSigned for another agent or token, or not by CoinGraph.
Using the guard with your own agent:signed answers are issued for your agent's wallet address. During the hackathon this is set up per team: open an issue on GitHub or email support@coingraph.ai. Decode any refused buy with npx tsx scripts/revert-reason.ts <txHash>.

Reading a response

GET /api/check (shortened)
{
  "symbol": "TRX",
  "orderUsd": 1000,
  "verdict": "proceed",              // proceed | caution | avoid
  "findings": [                      // worst first, each with level and text
    { "level": "ok", "check": "oracle_price",
      "text": "PancakeSwap price $0.303 vs Atlas Oracle TRX/USD $0.303: 0.13% apart." }
  ],
  "numbers": { "liquidityUsd": 276454, "priceImpactPct": 0.73, "atlas": { … }, "cournot": { … } },
  "proof": { "recorded": true, "txHash": "0x…", "evidenceHash": "0x…", "explorer": "https://bscscan.com/tx/0x…" }
}

Treat anything other than proceed as a stop. A finding the check could not measure is never assumed safe.

Verify an answer

  1. Run a check on guard.coingraph.ai and click Download evidence.
  2. Hash the file with keccak256.
  3. Open the record on BscScan and compare it with the evidenceHash in the transaction.

The signed verdict inside any guarded buy can be decoded with scripts/answer-in-tx.ts in the source code.
